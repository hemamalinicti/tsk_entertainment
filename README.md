# TSK Entertainments

> Premier Event Planning, Luxury Weddings & Milestone Celebrations across Tamil Nadu.

A modern, responsive, and performance-optimized static website crafted for **TSK Entertainments**, featuring rich visual media, transparent pricing tiers, an interactive 4-step event planner with WhatsApp quotation dispatch, and bespoke event management services.

---

## 🌟 Key Features

- **Dynamic 4-Step Planner Wizard (plan-my-event.html)**:
  - Step 1: Event Category Selection (Weddings, Birthdays, Décor, Corporate, Celebrities).
  - Step 2: Guest Count, Date, City Selection (Chennai, Madurai, Coimbatore, Salem, Trichy, etc.) & Curated Packages (Silver, Gold, Platinum).
  - Step 3: Bespoke Add-ons (Photography & Drone, DJ & Live Music, Catering, Grand Entry & SFX).
  - Step 4: Contact details review and instant formatted WhatsApp quotation message generation.
  - Mobile-optimized collapsible summary drawer with 48px touch targets and iOS-zoom-safe inputs.

- **Responsive Mobile Navigation**:
  - Clean sticky header with brand identity and high-contrast styling.
  - Slide-down mobile drawer with quick navigation links, direct booking hotlines, and Instagram integration.
  - Zero layout collision on small viewports (320px–414px).

- **Streamlined Hero Sections**:
  - High-impact, balanced hero banners with optimized typography and background imagery.
  - Quick-jump anchor bars on Services & Packages for rapid browsing.

- **Design System & Cultural Aesthetics**:
  - Curated South Indian heritage palette: Kumkum Red (#8e1b2e), Turmeric Gold (#e8a317), Leaf Green (#1f4d3a), and Warm Ivory background (#fbf6ec).
  - Strict accessibility standards (WCAG AAA contrast on key actions and form controls).

## 🚀 Getting Started

To view the website locally:

1. Clone the repository:
   \\\ash
   git clone https://github.com/hemamalinicti/tsk_entertainment.git
   \\\

2. Navigate into the directory:
   \\\ash
   cd tsk_entertainment
   \\\

3. Open \index.html\ in any modern browser, or launch a local server:
   \\\ash
   # Using Python
   python -m http.server 8000

   # Or using VS Code Live Server extension
   \\\

## 🌐 GitHub Pages Deployment

To publish this website live for free via GitHub Pages:
1. Go to repository **Settings** &rarr; **Pages**.
2. Under **Build and deployment** &rarr; **Branch**, select \main\ and \/(root)\.
3. Click **Save**. The live URL will be active at:
   \https://hemamalinicti.github.io/tsk_entertainment/\
